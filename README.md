# Algorithm Visualizer

An interactive algorithm visualization platform built using HTML, CSS, JavaScript, Python, Flask, and C.

## Features

- Visualize sorting algorithms
- Visualize searching algorithms
- Step-by-step execution
- Algorithm complexity information
- Comparison and swap statistics
- Interactive controls

## Tech Stack

- HTML
- CSS
- JavaScript
- Python
- Flask
- C

## Algorithms

### Sorting
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Searching
- Linear Search
- Binary Search
